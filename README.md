# مِرقَام للجوال (PWA → APK) — النسخة النهائية

## الملفات (لا تغيّر أسماءها)
`index.html` (التطبيق) • `sw.js` (العمل بلا إنترنت والإشعارات) • `manifest.webmanifest` (بطاقة التطبيق) • `icon-192.png` و`icon-512.png` (الأيقونة)

## الخطوات
1. GitHub: أنشئ مستودعاً **Public** باسم `mirqaam` ← Add file ← Upload files ← ارفع الملفات الخمسة ← Commit.
2. Settings ← Pages ← Branch: main ← Save. بعد دقيقة يظهر رابطك: `https://اسمك.github.io/mirqaam/`
3. افتح `pwabuilder.com` ← الصق الرابط ← Start ← Package for stores ← Android ← Generate Package.
4. ينزل ملف ZIP فيه `.apk` ومفتاح التوقيع (**احتفظ به** لتحديث التطبيق لاحقاً). أرسل الـ APK على تليجرام وثبّته (فعّل «السماح بالتثبيت من هذا المصدر»).
5. آيفون: افتح الرابط في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

## تحديث التطبيق لاحقاً
ارفع الملفات الجديدة فوق القديمة في GitHub، وغيّر رقم النسخة في أول سطر من `sw.js` (مثل `mirqaam-v9` ← `mirqaam-v10`). يتحدث عند المستخدمين تلقائياً دون إعادة بناء الـ APK.

## تسجيل الدخول بحساب Google (حقيقي)
الكود جاهز، ويحتاج منك **معرّفاً (Client ID)** تنشئه مرة واحدة، لأن Google لا تسمح بالدخول دون مشروع باسمك. المعرّف ليس سرّاً، ويوضع داخل الملف.
1. افتح `console.cloud.google.com` ← مشروع جديد (New project).
2. APIs & Services ← **OAuth consent screen** ← External ← اكتب اسم التطبيق وبريدك ← Save.
3. من **Audience** أضف بريدك في Test users (أو اضغط Publish app ليدخل أي شخص).
4. Credentials ← Create credentials ← **OAuth client ID** ← النوع **Web application**.
5. في **Authorized JavaScript origins** اكتب العنوان التالي بالضبط، بلا مسار ولا شرطة في النهاية:
   `https://abo-albaraa-max.github.io`
6. اضغط Create وانسخ **Client ID** (ينتهي بـ `.apps.googleusercontent.com`).
7. افتح `index.html` وابحث عن السطر `const GCID="";` وضع المعرّف بين علامتي الاقتباس، ثم ارفع الملف إلى GitHub مرة ثانية (يتحدث التطبيق تلقائياً).
   - أو أرسل لي المعرّف وأضعه في الملف لك.
ملاحظات: يعمل الدخول من رابط التطبيق المنشور (https) فقط، وليس من الملف على الجهاز. وفي الإعدادات يظهر زر «تسجيل الدخول بحساب Google» ثم زر Google الرسمي. وهو يعرّف حسابك (الاسم والبريد والصورة)، وليس مزامنة بين الأجهزة.

## ملاحظات صريحة
- الإشعارات تصل والتطبيق مفتوح أو في الخلفية. وعند الإغلاق التام أحاول إيصالها عبر مزامنة الخلفية، لكن أندرويد لا يضمن ذلك.
- المرفقات تُحفظ على الجهاز (حتى 25MB للملف) ولا تدخل في النسخة الاحتياطية JSON.
- الخطوط الجميلة تحتاج إنترنت أول مرة ثم تعمل بدونه.
