# مِرقَام للجوال (PWA → APK)

## 1) نشر التطبيق مجاناً على GitHub Pages
1. أنشئ حساباً مجانياً على github.com ثم New repository باسم `mirqaam` (Public).
2. اضغط Add file ← Upload files، وارفع **ملفات المجلد كلها** (index.html وmanifest.webmanifest وsw.js والصورتين)، ثم Commit.
3. Settings ← Pages ← Branch: main ← Save.
4. بعد دقيقة يظهر رابطك: `https://اسمك.github.io/mirqaam/` — افتحه للتجربة.

## 2) آيفون وأندرويد بدون APK (مجاناً)
- آيفون: افتح الرابط في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
- أندرويد: افتح الرابط في Chrome ← القائمة ← تثبيت التطبيق.

## 3) تحويله إلى ملف APK (مجاناً، لا تحتاج تثبيت أي برنامج)
1. افتح pwabuilder.com من المتصفح.
2. الصق رابط تطبيقك ثم Start، وانتظر نتيجة الفحص.
3. اضغط Package for stores ← Android ← Generate Package (اترك الخيارات الافتراضية).
4. ينزل ملف ZIP: فيه ملف `.apk` وملف `.aab` ومفتاح التوقيع. **احتفظ بمفتاح التوقيع** لتحديث التطبيق لاحقاً.
5. أرسل ملف `.apk` عبر تليجرام أو واتساب. على الجوال: افتحه وفعّل «السماح بالتثبيت من هذا المصدر».

## ملاحظات
- البيانات تُحفظ على الجهاز وتعمل بدون إنترنت. خذ نسخة احتياطية من الإعدادات بين وقت وآخر.
- آيفون: لا يوجد ملف تطبيق مجاني، والطريقة أعلاه هي الأنسب.

## تسجيل الدخول بحساب Google (بعد النشر)
1. console.cloud.google.com ← مشروع جديد ← OAuth consent screen (External، أضف بريدك مستخدماً تجريبياً).
2. Credentials ← Create credentials ← OAuth client ID ← نوع **Web application**.
3. في Authorized JavaScript origins ضع رابط موقعك فقط (مثل `https://اسمك.github.io`) بلا مسار.
4. انسخ Client ID والصقه في التطبيق: الإعدادات ← حساب Google ← Client ID. تظهر أيقونة تسجيل الدخول.
ملاحظة: يعرّف هويتك (الاسم والبريد والصورة) فقط، وليس مزامنة سحابية.
